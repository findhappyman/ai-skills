# 小红书格式指南

目标：生成用户可以直接复制的小红书文案和发图顺序。默认不自动发布。

## 输出文件

- `<主题>_小红书.txt`
- `<主题>_小红书_图文短版.txt`，当图文正文超过 1000 字时生成

## 格式规则

- 小红书正文是纯文本，不使用 Markdown。
- 不使用 `**加粗**`，强调统一用 `「重点」`。
- 标题单独一行，正文从下一行开始。
- 小标题用 `「小标题」` 或短句，不用 Markdown `##`。
- 引用可用 `｜` 开头。
- 结尾可以有一句行动建议，但不要写自动化提示、脚本说明或平台内部备注。
- hashtag 放在文末，数量克制，优先 3-6 个。

示例：

```text
标题：别急着用 AI 替你做决定

很多人用 AI 的方式，其实像把方向盘直接交出去。

「真正要保留的是判断」

AI 可以帮你整理路线、比较方案、提醒风险，但最后要去哪里，还是得由你决定。

#AI工具 #个人知识管理 #写作
```

## 字数与入口

- 图文笔记正文建议不超过 1000 字。
- 超过 1000 字时，优先生成短版；如果用户明确要求长文，再使用长文/文章入口。
- 发图顺序：封面图 → 段落配图 01 → 段落配图 02 → 信息图。

## 自动化边界

只有用户明确要求自动化小红书时，才打开创作者中心。始终只保存草稿或停在发布前编辑页，不点击最终发布。遇到登录、扫码、验证码、权限或 UI 变化，暂停让用户处理。
